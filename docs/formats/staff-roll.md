# staff_roll 制作人员名单（CSV / Shift-JIS）

`data\text\staff_roll\staff_roll_*.lst`（12 个文件，约 260–380 行/文件），
游戏 ED 制作人员名单的滚动字幕数据源。CSV 格式，文本列为 **Shift-JIS**。

> 语义标注：布局/编码已验证 ✅；列语义除坐标/颜色外多为数据推断 ⚠️，
> 需实机观察或逆向 staff_roll 渲染代码最终确认。

## 1. 文件头

```
A,B,C,
```

| 字段 | 观测值 | 推测语义 ⚠️ |
|------|--------|------------|
| A | 4（11 个文件）、5（ex2） | 格式版本 |
| B | 4–30 | 组（页）数——行内组号最大值与 B 吻合（如 st 文件组号 0–4） |
| C | 0（11 个文件）、225（c3） | 滚动起始偏移/初始 Y |

## 2. 数据行

```
Staff_Eiri_Mizuki_j,,御月 英理,0,0,0,1,1,720,205,0,1000,0,0,0,0,255,0,0,0,0,
key                  ↑ 空列  ↑文本  ↑c4-6   组  c8  X    Y   c11 1000        RGB(A?)    尾标
```

| 列 | 例值 | 推测语义 ⚠️ |
|----|------|------------|
| 1 | `Staff_xxx_j` | 标识符（`_j` 后缀疑为 jpn 语言槽，可能支持多语言替换文件） |
| 2 | （空） | 未使用 |
| 3 | `御月 英理` 等 | **显示文本**（SJIS；声优真名不需翻译，角色名/栏目标题需翻译） |
| 4–6 | 0,0,0 | 未观察到非 0，语义未知 |
| 7 | 0（标题行）、1..n | **组号**（分页/分栏；同组同屏） |
| 8 | 1（st）/ 1000（c3） | 字号或缩放 ⚠️（c3 全系 1000） |
| 9–10 | 720/960, 205–534 | **屏幕坐标 X,Y**（双列交替：st 为 720/960，c3 为 340/737；Y 步进 47） |
| 11 | 0 | 未知 |
| 12 | 1000 | 疑速度/时间参数（1000 基准） |
| 13–16 | 0 | 未观察到非 0 |
| 17–20 | 255,0,0,0（st）/ 255,255,255,255（c3） | **RGBA 颜色**（st 文本黑、边框白？c3 纯白） |
| 21 | 0/1 | 尾标：标题行（CAST 等）=1，成员行=0（st）；c3 相反（标题 1、成员 0——一致：标题=1） |

## 3. 汉化注意点

- 文本列写中文需转 **Shift-JIS 可编码**（或用工具支持的字库外字）；游戏用 jpn_glyph
  渲染还是独立字体渲染待确认（若在 HIP 字库外，可能走系统字体路径）。
- 翻译应保持行长与原版接近（坐标是固定排版，超长会重叠/溢出）。
- 文件共 12 个（角色线 9 个 + ex/c2/c3），内容大量复用（CAST 表几乎相同）。
