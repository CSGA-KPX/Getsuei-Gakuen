逐条见 `work/inventory/ruby-fix-list.tsv` 的 `R` 行。

## 5. 结论

- 「只保留写 A 读 B 与着重号」这条约定**执行到位**：635 个标签里 615 个属于这两类或在合理范围。
- 真正要动的只有 **53 处**（9 拼音 + 42 冗余 + 2 长音符），改动只影响 `work/atf-cn` 的
  `value` 字段，不需要重新翻译，也不需要动 `work/galtransl-proc`（源翻译）。
- ⇒ **建议写一个 `scripts/fix-ruby.fsx`**（表驱动，映射内联），做法同 `gen-ending-cn.fsx`。

### ⚠️ 执行顺序（别踩这个坑）

`fix-ruby.fsx` 改的是 `work/atf-cn`，而 **`galtransl.fsx import` 会用 `work/galtransl-proc`
整个重写 `work/atf-cn`，把修好的 ruby 覆盖掉**。所以顺序必须是：

```
（确认 galtransl-proc 定版，不再重跑 import）
  → fix-ruby.fsx（改 work/atf-cn）
  → font-rebuild.fsx all
  → verify-patch.fsx
  → 装机
```

若将来必须重跑 `import`，要么把 53 条修复内联进 `galtransl.fsx` 的合并后处理，
要么 import 之后再跑一次 `fix-ruby.fsx`（幂等：已修的不会再命中）。
