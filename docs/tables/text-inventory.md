### ⚠️ text_effect* 是特效资源清单，**不要翻译**（2026-10-19 查证）

8 个 `text_effect*` pac 共 101 条，内容形如：

```
eff_001桜の花びら
eff_006a斬撃（刀）汎用「a」
eff_012b血飛沫（赤）「b」
eff_053ハザードの瘴気
```

判据：

1. 每条都是 `eff_###` 编号 + 日文**美术描述**，括号里是技术变体（`（通常）`/`（見上げ）`/`汎用`/`「a」`）—— 开发清单，不是台词。
2. **ADVScript（`scr_*.pac` 内的 bin）里确实存在 `eff_053`/`eff_038`/`eff_015`/`eff_009`/`eff_012b`/`eff_033` 等字符串查找**（实测命中），
   即编号是**程序标识符**，改文本有破坏脚本调用的风险。
3. 内容是美术资源描述（樱花花瓣/血沫/集中线/白屏），不可能上屏给玩家看。

⇒ **结论：一律不译**，保持原样。这也回答了「战斗演出会不会翻到硬编码效果名」—— 会，所以这些包必须原样跳过。
